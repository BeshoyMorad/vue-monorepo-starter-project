# i18n (vue-i18n)

- App messages are JSON only, in `apps/<app>/src/locales/{locale}/{namespace}.json`. Filename is the key prefix: `en/auth.json` → `t('auth.title')`.
- Messages shared by several apps live in `packages/locales/src/common/{en,ar}.json` (namespaces `common`, `errors`, `nav`). The app loader merges them in, and app messages win on a clash.
- Supported locales: `en`, `ar`. Add both files for every namespace. The stored locale (or the site default) is loaded at bootstrap; other locales are lazy-loaded.
- Do not put `locales/` next to components or modules. Do not store messages in `.ts`. Do not use SFC `<i18n>` blocks for app copy.
- App namespace files have no extra wrapper. `auth.json` is `{ "title": "..." }`, not `{ "auth": { "title": "..." } }`. The shared `common/*.json` files keep their wrapper because they hold several namespaces.
- `t()` / `$t()` only. Hard-coded UI strings belong in a JSON file first.
- After adding an app namespace file, add it to `MessageSchema` in `apps/<app>/src/locales/messages.ts`.
- Locale config, formats, and `getStoredLocale()` come from `@workspace/locales`. Do not copy them into an app.
- i18n Ally: `.vscode/settings.json` (`{locale}/{namespace}.json`, `namespace: true`). Do not change the app folder shape without updating that config.
